# Start here

Read [README.md](../README.md) for the current layout and Python build commands. The active C++
platform is `platform/` version 0.6.0, with a chassis 04 logical jar interlock and a C++ animated
renderer for native and WebAssembly builds. The document foundry
remains version 0.7.0.

The included firmware is an unfinished safe starter, so product acceptance is not complete. Physical
HWIL, a real board, and electrical or appliance safety validation are not implemented. Older P6 and
chassis 03 release records in this source tree are historical.
