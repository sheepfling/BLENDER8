# Owner working material

`private/` holds the local, owner-only interpretation of the accepted customer correspondence. It is
ignored by Git and excluded from the complete source bundle. Keep it outside the New Employee
handoff. The
recipient contract remains the accepted correspondence and supplier documents; an owner note must
not add a hidden customer requirement or revive a retired implementation recipe.

The [semantic crosswalk](requirements-crosswalk.json) maps earlier clauses to the accepted mail.
The [editorial record](CORRESPONDENCE-EDITORIAL-RECORD.md) explains the authored exchange, and the
[ownership audit](DOCUMENT-OWNERSHIP-AUDIT.md) records source boundaries. The private mapping is
local to this checkout. Back it up through an owner-controlled channel if it needs to survive a
fresh clone.
