Operation and execution boundaries
The rear switch initially requests ON. Click RUN to advance power settling and execution; the POWER ON/OFF control toggles the physical switch. The pixel probe reads actual contacts and writes the real LCD; its motor is intentionally off. The selected image is C++ firmware compiled into this application. In a fresh component-bench session, 2S MOTOR EXHIBIT runs a journaled electrical test sequence, not finished product firmware. Watch the motor accelerate and coast, or lift the jar to remove permission.
Hold P or Space; releasing outside the control still releases the momentary input. Changing tabs or losing focus releases held inputs and pauses logical time. Simulation pause is not electrical STOP. Click the canvas and RUN to resume; hidden time is never caught up. MCU RESET resets the existing device; Restart session recreates the entire machine. The browser is not a physical HWIL driver.
Use the canvas tabs for Thermal measurements, Truth overlays, Motor histories and Systems. Thermal plots show nominal sensor-wire estimates and actual firmware ADC reads; Truth adds case, sensor, air, food (if present) and room states. Histories use logical time and retain ten minutes. Missing and stale ADC readings remain explicit.
All scene drawing, input hit-testing, animations and component state are C++. The browser only presents a C++ RGBA framebuffer and forwards events. Component and firmware diagnostic views remain available at the original workbench.
