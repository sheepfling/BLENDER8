# B8 platform 0.6.0

> This records the original 0.6.0 delivery. The integrated checkout subsequently built and tested
> the real Emscripten target; see [local build verification](../../docs/BUILD-VERIFICATION.md).

See [VALIDATION-0.6.0.md](VALIDATION-0.6.0.md) for the executed evidence and
[ANIMATED-WORKBENCH.md](ANIMATED-WORKBENCH.md) for operation and interface detail.

This release adds the C++ graphical application and thin worker/canvas shell, not a second simulator
or a finished firmware solution. Native operation is implemented and tested. Actual Emscripten
compilation and browser-Wasm execution remain outstanding; no compiled B8 Wasm binaries are
included. B8 interface03 and chassis04 behavior are retained.
