\section*{Description}
The XO8-33 contains a quartz resonator, sustaining amplifier and logic-output buffer. It produces a continuous clock after its supply and output-enable input are valid for the specified start interval. The receiver uses an external-clock input; no resonator-drive amplifier or external crystal load capacitors are required at that input.

\begin{Notice}{CLOCK PRESENT IS NOT CLOCK QUALIFIED}
Edges during startup do not establish frequency accuracy. Allow the full start interval or use receiver-side clock qualification. A processor's internal reset-release timer is not part of this module.

Place the bypass capacitor close to VDD and GND. Keep the clock route short with a continuous return path. Separate it from switching-power and high-current return paths. Reserve a source-series damping position when needed by the load and trace geometry; determine its value from the implemented interconnect.

One OUT terminal does not imply unlimited fan-out. Add the receiver capacitances, trace capacitance and probe load. Use a qualified distribution buffer when the total exceeds the specified load. Devices share a timebase only when their clock inputs are actually connected to it; a data bus alone does not distribute the clock source.
\section*{Startup and interrupted supply}
After each invalid-supply or OE-low interval, the full start interval applies again. OUT must not be used to infer retained host state. Temporary supply loss can interrupt edges while the receiving device remains powered; receiver reset, fallback and fault policy are independent design decisions.
\section*{Application boundaries}
The published frequency allowance is not a zero-jitter guarantee.
